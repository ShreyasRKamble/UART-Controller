# UART 16550 in SystemVerilog

A SystemVerilog implementation of a UART 16550 style controller, with a register interface, serial transmit and receive paths, FIFO support, modem control/status, and configurable baud timing.

The project targets a Cyclone V `5CGXFC7C7F23C8`. It was set up with Quartus Prime 25.1 Lite and Questa/ModelSim project files.

## Start here

1. Read the top-level interface in [`RTL/uart_16550_top.sv`](RTL/uart_16550_top.sv). Defaults are a 50 MHz clock, 115,200 baud, and FIFO depth 16.
2. Review the design block map below, then browse the corresponding RTL modules.
3. Open [`uart_16550_top.qpf`](uart_16550_top.qpf) in Quartus Prime, or [`UART_16550.mpf`](UART_16550.mpf) in Questa/ModelSim.
4. Use the [testbench index](TB/README.md) to choose a focused block test or an integrated test.

## Top-level interface

`uart_16550_top` exposes a simple 3-bit addressed, 8-bit host register interface (`addr`, `wr_en`, `rd_en`, `wr_data`, `rd_data`), UART serial pins (`rxd`, `txd`), and modem-control inputs and outputs. Reset is active-low (`rst_n`).

## Design map

| Area | RTL files | Responsibility |
| --- | --- | --- |
| Top-level controller | `uart_16550_top.sv` | Register map, configuration/control, and connection of UART functions |
| Register and status blocks | `uart_reg_interface.sv`, `uart_lcr.sv`, `uart_fcr.sv`, `uart_lsr.sv`, `uart_mcr.sv`, `uart_msr.sv`, `uart_scr.sv`, `uart_psd.sv`, `uart_divisor.sv` | Host register access, line/FIFO configuration, status, modem control, scratchpad, and divisor state |
| Transmit path | `uart_tx.sv`, `uart_tx_config.sv`, `uart_tx_fifo.sv` | Serial transmit, configurable framing, and buffered transmit |
| Receive path | `uart_rx.sv`, `uart_rx_16x.sv`, `uart_rx_config.sv`, `uart_rx_fifo.sv`, `uart_rx_synchronizer.sv`, `uart_rx_timeout.sv` | Serial receive, oversampling/configuration, synchronization, buffering, and receive timeout |
| FIFO and timing support | `uart_fifo.sv`, `uart_baud_gen.sv`, `uart_baud_gen_prog.sv`, `uart_baud_gen_16x.sv`, `uart_baud_gen_16x_prog.sv` | FIFO storage and fixed/programmed baud or 16x sample ticks |
| Shared definitions | `uart_pkg.sv` | Shared SystemVerilog types and constants |

The top-level file contains the integrated controller; several focused RTL modules also have their own testbenches for block-level review.

## Verification map

The `TB/` directory contains 26 SystemVerilog testbenches. They cover register blocks, FIFOs, baud generators, TX/RX behavior and configuration, synchronization, timeout, and loopback/top-level behavior. See [`TB/README.md`](TB/README.md) for the full index. The project files register the RTL and testbench sources for use in the FPGA and simulation tools.

## Repository layout

```text
RTL/                 Active design sources
TB/                  Testbenches and their index
SIM/                 Reserved for shared simulation scripts/support
archive/backups/     Local historical .bak snapshots (excluded from Git)
uart_16550_top.qpf   Quartus project
uart_16550_top.qsf   Quartus device and source assignments
UART_16550.mpf       Questa/ModelSim project with relative source paths
```

Quartus and Questa generated databases, reports, waveforms, and local workspace files are excluded by `.gitignore`. They can be regenerated by the tools and are not design sources.
